## 🚀 Installation Android

### Option 1: Termux (Recommandé Android)

1. Installez **Termux** depuis F-Droid: https://f-droid.org/packages/com.termux/
2. Ouvrez Termux et tapez:

```bash
pkg update && pkg upgrade -y
pkg install nodejs git -y
git clone https://github.com/afiss859-eng/lucifer-bot.git
cd lucifer-bot
npm install
cp .env.example .env
npm start
```

3. Scannez le QR code avec WhatsApp

### Option 2: Replit (Sans installer quoi que ce soit)

1. Allez sur https://replit.com
2. Créez un compte gratuit
3. Importez ce dépôt GitHub
4. Lancez le projet

## 👑 Système VIP

Le propriétaire attribue manuellement le statut VIP:
- `.addvip @membre` — Ajouter VIP
- `.delvip @membre` — Retirer VIP  
- `.listvip` — Voir la liste VIP

## 🔧 Commandes Propriétaire
